🌌 Quantum Canvas Ultimate: Universal Physics & Music Engine v5.0
Quantum Canvas Ultimate is a cutting-edge web application that creates a real-time, symbiotic experience between audio synthesis and 3D particle physics visualization. Designed with a futuristic, LCARS-inspired interface, it allows users to explore the relationship between music, chaos theory, and complex visual patterns.
🚀 Key Features
1. Unified Engine
Real-Time Symbiosis: All musical parameters (tempo, scale, effects) directly influence the 3D particle system, and physics metrics influence color, speed, and particle movement.
Audio/Video Recording: Capture your session, synchronizing the generated audio and the 3D visual output into a single .webm video file.
2. Physics & Visuals
Diverse Physics Models: Experiment with various models to drive particle behavior, including Lorenz/Rössler Attractors (Chaos), Orbital Gravity, Flocking (Boids), Vortex Dynamics, and Quantum Probability.
Procedural Visual Patterns: Initialize the 3D canvas with complex starting formations like Fibonacci Spiral, DNA Double Helix, Mandelbrot Set, and Cube Lattices.
Customizable Particles: Choose from various particle geometries (Spheres, Cubes, Tetrahedrons, Stars) and control count, size, and glow effects.
3. Music & Sequencing
16-Step Pattern Sequencer: Create rhythmic and melodic loops, with steps that can modulate melody, harmony, filter cutoff, or even visual properties.
Advanced Music Theory: Select from diverse musical scales (Pentatonic, Dorian, Japanese, Arabic) and set the global Root Note and Octave.
Interactive Keyboard: Use the pop-up virtual piano to play the synthesizer live with the current settings.
4. Evolutionary Engine (Genetic Algorithm)
Activate the Evolution Engine to automatically tune parameters based on predefined fitness criteria. Modes include:
Particle Behavior: Evolves force, damping, and time scale for stable dynamics.
Color Evolution: Optimizes hue, saturation, and brightness for aesthetic visual appeal.
Pattern Discovery: Finds musically interesting sequences and tempos.
🛠️ Technology Stack
This application is built as a single-file, high-performance HTML/JavaScript/CSS web immersive.
3D Visualization: Three.js (R128) is used for rendering the 3D particle system and physics simulation.
Audio Synthesis: Tone.js manages the polyphonic synthesizer, ADSR envelope, effects chain (Filter, Reverb, Delay, Distortion, Chorus), and real-time analysis.
Styling: Custom CSS, inspired by the futuristic LCARS (Library Computer Access/Retrieval System) interface, ensures a highly stylized and functional experience.
📝 How to Use
A. Getting Started
Click the ▶ START button in the center panel. This initializes the Tone.js Audio Engine. The AUDIO ENGINE status indicator will turn green.
The application will begin looping the current 16-step pattern based on the Tempo in the MUSIC THEORY section.
B. Configuring Physics
Navigate to the PHYSICS tab (Right Panel).
Select a Physics Model (e.g., Lorenz Attractor or Flocking (Boids)).
Adjust the Force Strength and Damping to control the chaos and stability of the particle movement.
Use Audio Reactivity to determine how much the music's volume and frequency data disrupts the physical simulation.
C. Creating Patterns
Go to the PATTERN SEQUENCER section (Left Panel).
Click the RANDOM button to generate a new 16-step pattern, or manually click the 0 / 1 cells to toggle steps on or off.
Change the Pattern Mode to define what the sequence controls:
Melody Control (Default): Plays a random note from the selected scale.
Harmony/Chords: Plays a full chord based on the root note.
Filter Modulation: Jumps the audio filter cutoff frequency.
Visual/Physics/Color: Triggers specific visual or physical changes.
D. Advanced Functions
Presets: Use the preset buttons (Ambient Space, Quantum Field, etc.) to instantly load curated combinations of audio and visual parameters.
Interactive Keyboard: Click the 🎹 KEYBOARD button in the footer to open the interactive piano overlay and jam along with your created pattern.
Recording: Click ⚫ RECORD to start capturing the visualization and audio. Click ■ STOP REC to stop and automatically download the final video file.
🧬 Evolutionary Tips
When using the Evolution Engine:
Target Selection: Choose an Evolution Mode (e.g., Color Evolution) that targets the parameters you want the algorithm to optimize.
Timing: The evolution runs one generation every 2 seconds. Monitor the Best Fitness value to see if the system is converging on an optimal state.
Stop/Start: Use the EVOLVE and STOP buttons to pause the genetic optimization process and lock in a configuration you like.
